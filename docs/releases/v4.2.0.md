# Legal Extractor v4.2.0 更新日志

## ✨ 新特性 (New Features)

- **安装即用，无需配置**：
  - 扫描件与图片识别不再要求申请/填写百度 Token——云端请求默认经官方中继网关完成
  - 试用期内全功能可用；激活后享更高识别额度
  - 高级用户仍可在 `config/conf.yaml` 自备 AI Studio Token 直连官方接口（优先于网关，亦是网关故障时的备用通道）
- **扫描件/图片的字段原位高亮**：
  - 扫描件 PDF 与借条照片等图片文书，字段值在原文上原位高亮并标注字段名，与文本层 PDF 体验一致
  - 双向回链：点击页面高亮定位记录卡；「定位原文」跳页闪烁对应高亮；编辑字段值实时联动
  - 识别不到坐标时自动回退 REC 角标，绝不画错位置
- **云端识别引擎升级**（PaddleOCR-VL-1.6 作业式接口）：
  - 解析进度为云端真实页级进度（此前为估算动画）
  - 大文档单作业整体受理，移除客户端分块与强制冷却等待

## 🐛 问题修复 (Bug Fixes)

- 修复发布版本激活码校验始终失败的问题（历史构建漏注入授权密钥，试用到期后无法激活）

## 🔒 安全 (Security)

- **应用零密钥**：云端凭据只存在于中继网关服务端；任何安装包、源码、配置模板均不含密钥
- 网关按机器码/授权码双档每日限额，作业归属跨机器隔离，滥用可精确封禁
- 发布策略测试固化上述不变量，回归即红

## 📦 升级说明

- 老用户已配置的 `baidu.token` 继续有效（自动迁移，等价新配置 `ocr.token`）；未配置过的用户无需任何操作
- `.docx` 文书仍为本地解析；Windows 系统 OCR 兜底逻辑不变
- 网关地址可经 `ocr.gateway_url` 覆盖；识别额度：试用档 20 次/日，授权档 200 次/日
