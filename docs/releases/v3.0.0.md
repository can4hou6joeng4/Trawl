# Legal Extractor v3.0.0 更新日志

## ✨ 新特性 (New Features)
- **全面转向百度 OCR 引擎**：
  - 移除腾讯云 OCR 全部逻辑，统一使用百度 PaddleOCR-VL 视觉大模型
  - 配置简化为单一 Token，降低用户接入门槛
- **并行提取引擎**：
  - 本地文本层解析支持多核并行加速，充分利用 CPU 资源
  - 引入超时控制机制，防止复杂 PDF 导致解析挂起
- **大文件物理分割**：
  - 超长 PDF（20 页以上）自动分块处理，逐块提交云端识别
  - 内置"避让重试"策略，应对百度 API 偶发的 500 错误
  - 分块间强制冷却期，保障云端服务稳定性
- **原子化按页解析**：
  - 每页独立提取法律实体，精确标注页码来源
  - 支持大批量文档的逐页结构化输出

## 🐛 问题修复 (Bug Fixes)
- 修复特定 PDF 导致的解析挂起问题（文本层探测增加 2 秒超时保护）
- 修复 `ParseDocument` 调用参数匹配错误
- 修复切片长度计算逻辑偏差
- 修复构建缓存导致时间戳失效的问题（改用 `go clean -cache`）

## 🔧 优化改进 (Improvements)
- **CI/CD 升级**：自动注入百度 Token 至构建产物，用户下载即用
- **架构清理**：深度清理冗余架构文件和过时的腾讯云测试代码
- **心跳反馈**：云端识别期间持续更新进度描述，防止 UI 假死
