# Legal Extractor v4.0.0 更新日志

## ✨ 新特性 (New Features)

- **「取证台」全新界面**：
  - 三阶段流程：落地拖放 → 解析进度 → 取证台，选择文件自动解析直达结果
  - 原文页面与结构化记录左右对照，记录卡一键"定位原文"跳到对应页
  - 页点导航标记有记录的页，支持 ←/→ 键盘翻页
- **校对即导出**：
  - 提取结果在记录卡上直接编辑修正，"已修正"标记随记录展示
  - 导出永远基于校对后的记录，人工修改随文件一并保存
  - 字段显隐即时生效，导出列随勾选字段裁剪（页码始终保留）
- **图片文书识别**：
  - `.jpg` / `.jpeg` / `.png` 接入百度 PaddleOCR-VL 云端识别
  - 未配置 Token 时给出明确的配置指引
- **体验细节**：
  - 后端稳定错误码统一映射为中文文案，取消操作显示中性提示而非报错
  - 云端配置实时读取，补填 conf.yaml 无需重启应用

## 🐛 问题修复 (Bug Fixes)

- 修复导出列丢失：表头改为全部记录字段并集，第一条记录缺失的字段不再导致整列消失
- 修复 CSV 与 Excel 导出口径不一致（统一包含页码列）
- 修复 Windows 系统 OCR 兜底路径提取不到任何字段的问题
- 修复云端解析失败时静默返回"未找到记录"的误导性结果

## ⚙️ 工程 (Engineering)

- 预览与提取共用提取骨架，统一试用校验与错误契约
- 本地文本层与 WinOCR 共用页级并发池，取消后立即停止计算
- 云端重试判定类型化（仅对 5xx 重试），移除逐页装饰性延迟
- 前端组件全面组件化并配套单元测试（51 个用例）

## 📦 升级说明

- 功能流程与配置方式不变：Token 仍通过 `config/conf.yaml` 或环境变量 `LEGAL_EXTRACTOR_BAIDU_TOKEN` 配置
- 原"预览数据"按钮已并入自动解析流程；导出前可随时在取证台校对修正
