# Legal Extractor v4.1.0 更新日志

## ✨ 新特性 (New Features)

- **真实原文渲染**：
  - 取证台左栏从示意占位页升级为真实原文：PDF 逐页高清渲染，自动适配高分屏
  - 图片文书（借条、证据照片）直接显示原图
  - 页码导航覆盖真实全文档页数，「定位原文」跳转真正的那一页
- **字段坐标高亮回链**：
  - 每条记录的被告 / 身份证号码 / 诉讼请求 / 事实与理由在原文页面上原位高亮并标注字段名
  - 双向回链：点击页面高亮 → 定位右栏记录卡；记录卡「定位原文」→ 跳页并闪烁对应高亮
  - 编辑字段值后高亮实时联动：人工修正与原文不一致时自动消失，改回即恢复
  - 扫描件 / 图片无文字层时自动降级为 REC 角标定位，行为与此前一致
- **匹配鲁棒性**：
  - 兼容部分 PDF 文字层的部首形码位与全角字形（NFKC 折叠），「⾝份证号码」也能匹配「身份证号码」
  - 同页多条记录的同名被告 / 同开头诉讼请求各自定位到自己的原文位置
  - 中文与数字混排行按字符视觉宽度加权，身份证号等数字串框选精确

## 🔒 安全 (Security)

- 原文读取采用新增的 `ReadCurrentDocument` 绑定：仅允许读取当前已解析的文书，不暴露任意路径读取，100MB 上限

## ⚙️ 工程 (Engineering)

- pdfjs-dist 动态分包，约 330KB 仅在打开 PDF 时按需加载，不拖慢启动
- 渲染 / 高亮全链路竞态防护：换文件令牌防护、渲染串行链与序列号调度、翻页即清残留、高亮与画布共用宽度基准
- 前端测试 51 → 84 用例；真实中文起诉状 PDF 端到端验证（渲染像素、双向回链、编辑联动、重复定位重播），零控制台错误

## 📦 升级说明

- 功能流程与配置方式不变：Token 仍通过 `config/conf.yaml` 或环境变量 `LEGAL_EXTRACTOR_BAIDU_TOKEN` 配置
- `.docx` 文书与扫描件仍以 REC 角标方式定位；OCR 坐标高亮列入后续增强
