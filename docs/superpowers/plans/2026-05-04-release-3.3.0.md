# 子迭代 4a：CHANGELOG + 版本号补齐 (v3.3.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 main 上已合入的 Iteration 2（取消 + ETA）和 Iteration 3（提取器拆分）写进 CHANGELOG，并把所有版本字符串统一对齐到 `3.3.0`。

**Architecture:** 纯文本/字符串变更，不动任何代码逻辑。三处需要同步：
1. `CHANGELOG.md` —— 头部插入 `[3.3.0]`、`[3.2.0]` 两段，文末追加两条 release tag 链接
2. `wails.json` —— `productVersion` + 顶层 `version` 由 `3.1.0` → `3.3.0`
3. `cmd/server/main.go::handleIndex` —— 索引路由返回的 `"version": "3.0.0"` → `"3.3.0"`

**Tech Stack:** 无新增依赖。仅 markdown / json / Go 字符串字面量。

**Spec:** `docs/superpowers/specs/2026-05-04-engineering-hygiene-trio-design.md` 第 3 节

## Task 2: 更新 `CHANGELOG.md`

**Files:**
- Modify: `CHANGELOG.md`

按时间倒序插入两段新条目，**且** 文末追加两条 release tag 链接。**两次 Edit 都要做完整**，不要只做一半。

- [ ] **Step 1: 在 `[3.1.0]` 之上插入 `[3.3.0]` 与 `[3.2.0]` 两段**

用 Edit 工具，old_string 为：

```markdown

```

new_string 为：

```markdown
本项目所有重要变更记录。格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [3.3.0] - 2026-05-04

### 重构
- 把 `internal/extractor/extractor.go` 按策略拆为 5 个聚焦文件：调度器（`extractor.go`）、本地 PDF 文本层与 Worker Pool（`pdf_local.go`）、Windows OCR 兜底（`pdf_winocr.go`）、DOCX 解析（`docx.go`）、正则解析与文本归并（`parsing.go`）。零行为变更，公共 API 与导出符号保持一致。

## [3.2.0] - 2026-05-04

### 新增
- 加载浮层加入"停止"按钮，桌面与 Web 模式均可中止进行中的提取任务
- 加载浮层显示估算剩余时间（"约 N 秒"/"约 N 分 M 秒"/"估算中..."/"即将完成"）
- 桌面端 `App.CancelExtraction()` Wails 绑定，串通 Iteration 1 的 `context.Context` 链路
- Web 端 `AbortController` 路径，配合后端 `c.Request().Context().Done()` 真实中止

## [3.1.0] - 2026-05-03
```
