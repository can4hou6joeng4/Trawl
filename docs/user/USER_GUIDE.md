# Legal Extractor 使用手册

> 适用版本：v4.2.0 及以上 ｜ 读者：日常使用者与现场实施人员
> 配置细节见 [配置指南](CONFIG_GUIDE.md)，报错处置见 [故障排查](TROUBLESHOOTING.md)

Legal Extractor 是一款桌面端法律文书提取工具：把起诉状等文书（Word / PDF /
扫描件 / 照片）自动提取为结构化记录（被告、身份证号码、诉讼请求、事实与理由），
在「取证台」上对照原文校对后，一键导出 Excel / CSV / JSON。

**开箱即用**：安装后无需注册、无需申请任何云服务账号或 Token。

---

## 1. 安装

从 [Releases 页面](https://github.com/can4hou6joeng4/legal-extractor/releases/latest)
下载对应平台安装包：

| 平台 | 文件 | 安装方式 |
|---|---|---|
| macOS（Intel/Apple Silicon 通用） | `legal-extractor_版本_darwin_universal.dmg` | 打开 dmg，把应用拖入「应用程序」 |
| Windows 10/11 x64 | `legal-extractor_版本_windows_amd64_setup.exe` | 双击安装器，按提示完成 |

**macOS 首次打开**若提示"无法验证开发者"：在应用图标上**右键 → 打开**，
或到 系统设置 → 隐私与安全性 → 点击"仍要打开"。

**Windows 首次打开**若出现 SmartScreen 蓝色提示：点击"更多信息 → 仍要运行"。

---

## 2. 三步上手

1. **拖入文书**：把文件拖到窗口中，或点击选择文件（支持 `.docx` `.pdf` `.jpg` `.jpeg` `.png`）
2. **等待解析**：进度条显示实时进度；扫描件/照片走云端识别，可随时点「停止」
3. **校对并导出**：在取证台核对每条记录，选择格式与保存位置后点「导出」

---

## 3. 取证台功能详解

界面为左右双栏：**左栏原文页面，右栏结构化记录**，二者双向联动。

### 左栏（原文）

- **字段高亮**：识别出的字段值在原文上以绿框原位标注字段名；
  **点击任意高亮**，右栏对应记录卡会闪烁定位
- **翻页**：左右箭头或 ←/→ 方向键；底部圆点标记「有记录的页」，点圆点直接跳页
- 扫描件如某页未能标注高亮，会以 REC 角标代替（点击同样可定位记录）

### 右栏（记录）

- **直接修改**：点击字段值即可编辑，修改后记录卡标记「● 已修正」；
  导出永远以校对后的内容为准
- 修改字段后原文高亮消失属正常（原文中已无该文字），改回即恢复
- **定位原文**：点记录卡右上角「↩ 定位原文」，左栏跳到对应页并闪烁该记录的高亮
- **字段显隐**：右上角「字段」按钮勾选要显示的列，同时决定导出包含哪些列
 （页码列始终保留）

### 导出

- 点右下角格式徽标切换 **XLSX / CSV / JSON**，选择保存位置后导出
- 导出完成后可直接点击打开文件

## 4. 文件类型与识别方式

| 文书类型 | 识别方式 | 需要联网 | 高亮精度 | 预期耗时 |
|---|---|---|---|---|
| Word（.docx） | 本地解析 | 否 | 无原文渲染（占位页） | 秒级 |
| 文字版 PDF | 本地解析 | 否 | 字符级（最准） | 秒级 |
| 扫描件 PDF | 云端识别 | **是** | 段落块级 | 每页约 30–60 秒 |
| 照片（.jpg/.png） | 云端识别 | **是** | 段落块级 | 约 30–60 秒 |

> 只有扫描件与照片需要联网。云端识别经官方中继网关完成，
> 应用与安装包不含任何云服务密钥。

---

## 5. 试用、激活与识别额度

- 安装即开始 **7 天全功能试用**（含云端识别）
- 试用到期后应用锁定；**激活**：打开激活窗口，把显示的 **8 位机器码**
  发给软件提供方，换取激活码填入即可
- 云端识别按机器每日计额：**试用期 20 次/日，激活后 200 次/日**
 （一次识别 = 一份文书提交一次；本地解析的 Word/文字版 PDF 不计额度）
- 更换电脑或重装系统后机器码可能变化，需重新申请激活码

## 6. 可选配置（绝大多数用户不需要）

配置文件位于应用同级的 `config/conf.yaml`（首次运行自动生成模板）：

- macOS：`legal-extractor.app/Contents/MacOS/config/conf.yaml`
 （访达中对应用右键 → 显示包内容）
- Windows：安装目录下 `config\conf.yaml`

可配置项、自备 Token 直连等见 [配置指南](CONFIG_GUIDE.md)。

## 7. 实施人员附录

### 7.1 交付验收清单

| 检查项 | 方法 | 预期 |
|---|---|---|
| 版本正确 | 安装包文件名 / 关于窗口 | 与交付单一致 |
| 本地解析可用 | 拖入一份文字版 PDF 或 .docx | 秒级出记录（断网也应通过）|
| 云端识别可用 | 拖入一份扫描件 | 进度条推进后出记录并有高亮 |
| 网关连通 | `curl https://ocr-gw.bobochang.cn/healthz` | 返回 `ok` |
| 导出可用 | 任意记录导出 XLSX 并打开 | 列齐、含页码列 |

### 7.2 网络要求

- 仅需放行 **HTTPS(443) 出站**，目标：`ocr-gw.bobochang.cn`（识别提交与进度）
  及百度云对象存储（识别结果下载，`*.bcebos.com` 等百度云域名）
- 无任何入站要求；Word/文字版 PDF 全程本地，可完全离线使用

### 7.3 激活流程（现场）

1. 引导用户打开激活窗口，记录 **8 位机器码**
2. 将机器码反馈给软件提供方，获取形如 `XXXX-XXXX-XXXX-XXXX` 的激活码
3. 用户填入激活码 → 显示已激活，云端额度自动提升

### 7.4 现场问题反馈

无法排除的问题，请收集：**报错提示截图 + 文书特征（页数/来源/是否扫描件）+
操作系统版本**，对照 [故障排查手册](TROUBLESHOOTING.md) 先行处置。
